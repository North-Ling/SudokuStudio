# Sudoku Studio · 浏览器数独工具

一个类似 SudokuPad 的浏览器数独工具，基于 **React + TypeScript + Vite + Canvas** 构建。

核心设计：数独网格的 **面（单元格）、边（两格之间的边框）、角（网格顶点）** 三类元素都是可交互、可编辑、可添加符号的一等公民。

## 运行

```bash
pnpm install
pnpm dev        # 开发模式（HMR）
pnpm build      # 类型检查 + 生产构建
pnpm preview    # 预览生产构建
```

## 功能

### 独立的出题窗口与解题窗口

- **解题窗口**：只渲染数字、角标、中标、着色、描边和擦除六种作答工具；约束和题面工具不会出现在界面中。
- **出题工作台**：提供题目名称、限制条件说明以及完整的约束与自由题面工具，数字会写成题目已知数。
- 题目名称与限制条件使用棋盘左上侧的紧凑信息卡；出题时可在原位置直接编辑，不占用棋盘上方整行空间。
- 颜色、约束及路径工具的参数区会跟随当前工具组就近展开，不再固定显示在侧栏末尾。
- 两种模式使用独立状态：未修改题目时往返切换会保留解题草稿；编辑过题目结构后，解题草稿会按新题面重置。

### 题库

- 题库使用独立页面展示，不再挤在工作台浮窗中；支持按名称、规则和约束搜索。
- 每道题包含名称、限制条件文本和 0–5 星难度（半星步进）；未填写限制条件时使用“标准数独规则适用”。
- 题库同时展示内置示例和保存在当前浏览器中的“我的题目”。
- 可从题库直接选择“进入解题”或“进入出题”。
- 具有固定语义的全局规则、杀手框、约束线、边符号、交汇点和盘外约束会自动生成只读规则描述；自由形状、文字、描边、自定义线及无数字杀手框不会自动添加。
- 出题工作台支持新建、保存、更新、删除、导入和导出；内置题目保存时会创建个人副本，不覆盖示例。
- 新建题目可快捷选择 6×6、8×8、9×9、12×12、16×16，或创建行列均在 1–16 内的自定义矩形网格。
- 五种标准尺寸可开启或关闭标准宫：分别使用 2×3、2×4、3×3、3×4、4×4 宫；关闭后可以使用描边工具绘制不规则宫边界。
- 标准宫题目自动检查行、列、宫；关闭标准宫后只检查行列；其他自定义比例完全关闭自动判错。

### 基础数独操作
- 填入大数字（已知数用深色、用户填入用蓝色，且已知数不可被覆盖）
- **角标**（按当前网格候选布局排列）与 **中标**（在格子中央紧凑显示）
- 单元格**多色着色**
- 填入字符时根据题目判错模式清理同行、同列及标准宫候选数
- 按题目网格配置检测行列宫、仅行列或完全不判错；冲突格会以红色底纹、边框和数字高亮
- 同数字高亮、选中框、撤销 / 重做、重置、清空
- 选择数字、角标或中标工具时，右侧就近显示字符罗盘，可在 `123` / `ABC` 间切换并输入任意单字符
- 数字、角标、中标和颜色采用经典小键盘交互：先选择格子，再点击字符或颜色完成一次输入；按钮不会保持按下，点击其他格子只改变选择
- 四种输入工具支持多格选择：普通单击总是重新开始；按住鼠标拖动才会沿正交相邻格扩展；按住 `Shift` 点击或拖动可追加任意离散区域，输入和删除会一次作用于全部选中格
- 再次点击当前格已有的相同字符或颜色即可移除，并为四种工具分别保留专用删除按钮；实体键盘快捷输入保持原逻辑
- 出题时可在单元格内叠加正方形、圆形、三角形、大叉号、八向小箭头或自定义文字 / 符号
- 描边、格内形状、杀手框和线路仍支持鼠标 / 触控连续笔划；着色改为选格后单次点击颜色

### 面 / 边 / 角符号（重点）
| 元素 | 可添加符号 |
| --- | --- |
| **面（单元格）** | 大数字、角标、中标、颜色 |
| **边（两格之间）** | 描边、蓝色装饰形状、白点（差 1）、黑点（2 倍）、不等号、V（和=5）、X（和=10）、自定义文字 |
| **角（网格顶点）** | 方向箭头（↑→↓←）、自定义文字 / 数字 |

点击边 / 角时会有命中预览高亮，再次点击相同符号即可取消。

边装饰使用独立的蓝色样式和 `decorations` 数据，不会与黑白点约束混淆；可选择粗线、叉号、三角、方形、圆形或自定义标记。

### 变形数独约束

约束按落点分组显示在出题工作台中，解题窗口只展示题面，不提供约束修改入口。

#### 全局额外限制

- **主对角线不重复**：开关开启后自动绘制两条主对角线，两条线上的数字分别不能重复。
- **无马数独**：国际象棋马步位置上的两个格子不能出现相同数字。

#### 格内区域约束

- **Killer 杀手笼**：点击 / 拖动上下左右相连的格子组成笼，填写和（可留空）；新增和移除格子时会保持区域连通，完成后的虚线笼框缩进网格内部显示。笼内数字之和等于提示数，通常不能重复。

#### 格中心线路约束

所有线路均可横向、纵向或斜向绘制，拖动中可反向回退；拉链线和之间线会自动绘制粗点。

| 线路 | 盘面颜色 | 规则 |
| --- | --- | --- |
| **温度计** | 灰色 | 灯泡端最小，沿温度计向外严格递增。 |
| **箭头** | 灰色 | 圆圈格是总和，箭头线上其余格子的和等于圆圈数字。 |
| **区域等和线** | 浅蓝色 | 线穿过每个宫时，在线上经过的数字之和都相等。 |
| **拉链线** | 浅紫色 | 与中心等距离的两个数字之和相等；奇数长度时该和等于中心位置的数字。 |
| **十和线** | 橙色 | 线上数字可以划分为若干个和为 10 的连续子段。 |
| **连番线** | 深紫色 | 线上是一组互不重复的连续数字，顺序可以打乱。 |
| **反约数线** | 黄绿色 | 不能出现线长的倍数或约数（1 除外），且线上数字之和是线长的倍数。 |
| **德国耳语线** | 深绿色 | 线上相邻数字至少相差 5。 |
| **荷兰耳语线** | 浅绿色 | 线上相邻数字至少相差 4。 |
| **奇偶线** | 红色 | 线上相邻数字奇偶性不同。 |
| **熵线** | 金色 | 任意三个连续格分别包含一个 1–3、一个 4–6、一个 7–9。 |
| **之间线** | 深灰色 | 线中间的数字位于两个端点数字组成的闭区间内。 |

#### 边框符号约束

- **连续 / 黑白点**：白点表示相邻格相差 1，黑点表示一格是另一格的 2 倍。
- **不等号**：在相邻格之间添加大小关系，不等号开口朝向较大的格子。
- **XV**：V 表示和为 5，X 表示和为 10；完整 XV 规则下，未标记边不能和为 5 或 10。

#### 交汇点或边上的点约束

- **瞭望塔**：在网格交汇点或相邻格的边上圈出若干互不相同的数字；与标记相邻的单元格中必须出现圈内列出的所有数字。

#### 盘外约束

- **摩天楼**：盘外数字表示从对应方向能看到的楼房数量，大数会挡住后面的小数。
- **X 和**：从边界向内看，第一个格子的数字 X 决定累加前几个格，盘外提示为这 X 个数字之和。例如一行以 3、1、4 开头，则 X=3，对应的 X 和为 8。
- **小杀手**：使用盘外虚拟格锚定和值和斜向箭头；箭头完全位于盘外且尖端指向边界交点。

编辑模式的擦除工具可以删除线路、杀手笼、边框 / 交汇点符号和盘外提示。当前版本负责题面编辑、显示、题库及 JSON 导入导出；规则自动判错与专用求解器校验不在本次范围内。

### 其他
- 键盘：数字或当前字符表中的字母填入/标记，`Shift+字符` 中标，`Ctrl/Cmd+字符` 角标，`方向键` 移动，`Del/0` 清除，`Ctrl+Z` 撤销，`Ctrl+Shift+Z` 重做，`Esc` 取消绘制
- 本地题库（`localStorage` 持久化）、JSON 导出 / 导入，以及组合题面、名称、星级和规则的高清 PNG 题目卡片导出
- 示例谜题：经典数独、约束展示、空白网格

## 架构

```
src/
├── ui/
│   ├── SudokuStudio.tsx # React 应用壳、模式与题目信息
│   ├── BoardCanvas.tsx  # Canvas 生命周期与输入引擎桥接
│   ├── ToolPanel.tsx    # 模式化工具面板
│   ├── ToolContext.tsx  # 当前工具参数控件
│   ├── LibraryPage.tsx  # 独立题库页面
│   ├── Modals.tsx       # 新建样式、导入与导出弹窗
│   └── toolDefinitions.ts
├── types.ts      # 数据模型（面/边/角 + 约束）
├── geometry.ts   # 网格布局与命中检测（cell/edge/corner）
├── grid.ts       # 标准尺寸、宫形、字符表与判错模式
├── model.ts      # 谜题创建/克隆/序列化 + 符号/约束辅助
├── history.ts    # 基于快照的撤销/重做
├── renderer.ts   # 独立于 React 的 Canvas 渲染引擎
├── app.ts        # 数独状态、命令与工具分发
├── input.ts      # 鼠标、触摸与键盘输入
├── library.ts    # 浏览器本地题库
├── puzzles.ts    # 示例谜题
└── main.tsx      # React 入口
```

React 负责界面声明、表单和弹窗生命周期；Canvas 绘制、几何命中与数独命令层保持框架无关，便于后续独立测试和复用。

## 数据模型要点

- `grid`：保存行列数、标准尺寸、宫形和判错模式；旧版 JSON 自动迁移为 9×9 标准宫
- `cells[rows][cols]`：每个格子含 `value / given / corner[] / center[] / colors[] / decorations[]`
- `title / rules`：题目名称与限制条件说明
- `edgeH[rows][cols-1]`：横向相邻两格之间的边（竖直线段），约束符号与自由装饰分开保存
- `edgeV[rows-1][cols]`：纵向相邻两格之间的边（水平线段），约束符号与自由装饰分开保存
- `corners[rows+1][cols+1]`：网格顶点
- `globalConstraints`：对角线与无马等全局开关
- `cages[] / thermos[] / arrows[] / lines[]`：区域和线路约束
- `lookouts[]`：交汇点或边上的瞭望塔提示
- `skyscrapers[] / xSums[] / littleKillers[]`：盘外提示
